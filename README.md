# Diabetes Risk AI Advisor (Clinical CDSS)

A Hybrid Clinical Decision Support System trained on real clinical data (NHANES) utilizing a Random Forest Classifier coupled with SHAP (SHapley Additive exPlanations) for model interpretability.

## Key Features
- **Predictive Engine:** Machine Learning risk assessment using core vitals.
- **Biomedical Engineering Metric:** Real-time calculation of **HOMA-IR** (Homeostatic Model Assessment for Insulin Resistance).
- **Explainable AI (XAI):** Live SHAP visual feedback explaining individual patient risk factors.
- **Clinical Reporting:** Dynamic, on-the-fly automated PDF medical report generation.
